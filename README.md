# 提瓦特 · 攻略工作台 v2.0

在同一个工作台切换「深渊配队」「角色养成」，选择对应模板并导出 PNG 攻略图。

## 深渊配队
- 保留原有角色选择、批量添加、拖放、攻略组、撤销和自动保存。
- 136 个角色条目，按名称、元素和星级筛选。
- 导出模板：金蓝双列、简约双列。两种模板均保持左右两列，每排四个角色。

## 角色养成
- 单独的草稿与撤销记录，切换模式不覆盖配队内容。
- 选择角色，添加多把武器、多个圣遗物方案，支持 4 件套、2+2 和单件祭冠。
- 编写主副词条、天赋优先级、关键命座、参考面板和补充说明。
- 按模块开关控制导出，空白模块自动隐藏；实时预览与 PNG 使用同一个排版器。
- 导出模板：详细养成长图（含圣遗物各部位）、精简养成卡。
- 支持导出、导入角色养成 JSON 草稿。

## 装备素材
- 252 把武器；63 套圣遗物、299 个部位。
- 按名称、类型、星级检索；圣遗物支持按部位筛选。
- 来源：用户提供的米游社原神观测枢目录与对应词条，整理于 2026-10-29。
- `equipment.json` 保存名称、分类、来源与图集坐标；`equipment/` 是工作台使用的 WebP 图集。
- 图集由来源图片适配生成，仅供工作台显示与导出。来源图片部分分辨率较小。

## 运行与部署

在本目录运行 `python -m http.server 8000`，再打开 `http://localhost:8000`。

GitHub Pages：Settings → Pages → Deploy from a branch → `main` → `/ (root)`。

配队草稿继续使用原来的 `teyvat-guide-v1`，养成草稿使用独立键 `teyvat-build-v2`。
草稿保存在当前浏览器，不会自动跨设备同步。需要跨设备时请导出、导入养成 JSON。

图片及游戏内容的相关权利归原权利人所有。工作台不自动生成配装推荐，具体内容由编辑者填写。
