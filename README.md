# 原神攻略工作台 v1.0

选择角色，编排多组配队和攻略说明，导出 PNG 攻略长图。

## 功能
- 136 个角色条目，按名称、元素和星级筛选
- 批量选择角色，每组可添加多个角色位并自动换行
- 编辑攻略标题、说明与组标题
- 自动保存浏览器草稿，支持撤销
- 导出 PNG 长图，可预览、下载或打开原图保存

## GitHub Pages
在仓库 Settings → Pages 中选择 Deploy from a branch，分支 main，目录 / (root)。

## 本地运行
在本目录运行 `python -m http.server 8000`，然后打开 http://localhost:8000 。

草稿保存在当前浏览器，不会跨设备同步。角色素材来自米游社原神观测枢，相关权利归原权利人所有。
